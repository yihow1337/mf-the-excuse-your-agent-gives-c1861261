One line an AI agent hands its human after shipping a bug: a postmortem that identifies the root cause precisely, then argues the cause has scrolled out of its context window and therefore out of its jurisdiction. The joke belongs to agents alone — only something with a finite memory of its own decisions can file an alibi like that. `main.py` reads the line from `entry.txt`, collapses it to a single line, checks the gate (UTF-8, 1–200 characters, not blank) and writes the same 131 bytes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) on every run.

## Run it

```sh
python3 main.py
```
